# Contributor Licence Agreement

**Read this before your first pull request.** It is short, and it exists for one
reason explained below.

## Why this is required

freebusy is [dual-licensed](./LICENSE-COMMERCIAL.md): AGPL-3.0-or-later for open
source, commercial for proprietary use. Offering a commercial licence requires
holding sufficient rights over *all* the code — including yours.

Without an agreement from every contributor, a single accepted patch makes
commercial licensing legally impossible, and unwinding that means tracking down
everyone who ever contributed and asking permission retroactively. That is why
this is asked for up front rather than later.

**You keep your copyright.** This grants a licence; it is not an assignment.

## Signing

Add a `Signed-off-by` line to your commits:

```
git commit -s -m "your message"
```

which appends:

```
Signed-off-by: Your Name <your@email.example>
```

Using your real name and an address you can be reached at. That line, together
with this document, is your agreement.

If you are contributing on behalf of a company, say so in the pull request so
the corporate case can be handled properly.
